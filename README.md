# د معلوماتو نړۍ — WhatsApp Bot

دا بوټ د WhatsApp ګروپونو لپاره د پوښتنو ځوابولو، محلي معلوماتي زېرمې او انټرنېټي سرچینو لټون ملاتړ کوي.

## اوسنی حالت

د پوښتنو او ځوابونو برخه، د انټرنېټي سرچینو لټون او د سرچینو پر بنسټ د AI پښتو ځوابونه فعال دي. د ګروپ نظم ساتنه هم فعاله پاتې ده: کنځل، سپکاوي، لینکونه، چټک او تکراري سپم، د چینلونو او Status فارورډونه.

## نوي تنظیمات (Environment Variables)

- `ALLOWED_GROUPS` — د ګروپونو JID لېست سره په کاما جلا؛ که یې وتړئ، بوټ یوازې په همدې ګروپونو کې کار کوي. که تش وي، په ټولو ګروپونو کې کار کوي (پخوانی چلند). د ګروپ JID د ګروپ د لینک څخه یا د بوټ له لاګونو موندلی شئ.
- `ALLOWED_LINK_DOMAINS` — د اجازې لرونکو وېب پاڼو لېست (لکه `bbc.com,example.com`)؛ د دې پاڼو لینکونه نه حذفیږي. که تش وي، ټول لینکونه حذفیږي (پخوانی چلند).
- `ALLOWED_LINK_SENDERS` — د اجازې لرونکو غړو لېست (د WhatsApp شمېرې)؛ د دوی لینکونه نه حذفیږي (لکه د ګروپ مدیران).
- `ENABLE_HISTORY_CLEANUP` — که `false` وي، د پخواني تاریخ لینکونه نه حذفیږي. ډیفالټ: پرانیستی.
- `WARNING_MUTE_ENABLED` — د درېیم اخطار وروسته د لنډمهاله محدودیت فعالول؛ ډیفالټ: `true`، د بندولو لپاره `false`.
- `WARNING_MUTE_DURATION_MINUTES` — د محدودیت موده په دقیقو کې؛ ډیفالټ: `120` (دوه ساعته)، اعظمي `1440` دقیقې.
- `RESET_WHATSAPP_SESSION`، `WHATSAPP_PHONE`، `SUPABASE_URL`، `SUPABASE_SERVICE_ROLE_KEY`، `OPENROUTER_API_KEY` — پخواني سره.
- `OPENROUTER_MODEL` — اختیاري؛ ډیفالټ: `openai/gpt-6-luna`.
- `AI_MAX_OUTPUT_TOKENS` — د AI د ځواب اعظمي اوږدوالی؛ ډیفالټ `1400` دی؛ له `500` تر `2000` پورې ارزښت منل کېږي. لوړ حد د اوږد ځواب امکان زیاتوي، خو دقت نه تضمینوي.

## ازموینې

`npm test` — د نظم ساتنې کړنې (کنځل، لینک، تکرار، اخطارونه) په جلا توګه ازمویي؛ بوټ نه پیل کیږي.

## د انټرنېټي لټون سرچینې

بوټ د عادي پوښتنو لپاره په موازي ډول دا سرچینې لټوي:
- DuckDuckGo د ویب پاڼو د موندلو لپاره
- Wikipedia پښتو
- Wikipedia انګلیسي
- GDELT د تازه خبرونو او بدلېدونکو موضوعاتو لپاره

د سرچینو پایلې د سرلیک، لنډ اقتباس او اصلي لینک سره وړاندې کېږي. د خبرونو د تازه والي او د سرچینو د اعتبار لپاره اصلي لینک وګورئ.

## د مفصل پښتو ځوابونو فعالول

د سرچینو د پایلو پر بنسټ د مفصل، منظم او سرچینه‌محوره پښتو ځواب لپاره OpenRouter API کارول کېږي، که API key تنظیم وي. د OpenRouter حساب او API key جوړ کړئ، بیا د SillyDev د Environment Variables/Secrets برخه کې دا ارزښتونه تنظیم کړئ:

- `OPENROUTER_API_KEY` = ستاسې شخصي API key
- `OPENROUTER_MODEL` = `openai/gpt-6-luna` (اختیاري؛ که نه وي، همدا ډیفالټ دی)

**API key هېڅکله په GitHub فایلونو، عام پیغامونو یا سکرین‌شاټونو کې مه خپروئ.** د `openai/gpt-6-luna` کارول د OpenRouter د حساب/بیلینګ له شرایطو سره تړاو لري. که API key نه وي، اعتبار/بیلانس بسنه ونه کړي، یا AI ناکام شي، بوټ به د موندل شوو سرچینو سرلیکونه، لنډ اقتباسونه او لینکونه وښيي.

## فعالول او ازموینه

1. په SillyDev کې پروژه Restart یا Redeploy کړئ څو د GitHub تازه کوډ پورته شي.
2. په WhatsApp ګروپ کې یوه پوښتنه ولیکئ؛ د تازه خبر لپاره د خبر، تازه، نن یا اوسنیو معلوماتو پوښتنه هم وازمویئ.
3. د بوټ د HTTP خدمت د `/health` مسیر وګورئ. د `webSearchProviders` ارزښت د لټون سرچینې ښيي؛ `aiSummarization: true` معنا لري چې د لنډیز API key تنظیم شوی دی.

## مهم محدودیتونه

- ویب لټون تل بشپړې یا بې‌خطا پایلې نه ورکوي.
- کله چې د AI API key نه وي، بوټ د سرچینو اقتباسونه ښکاره کوي، خو د هغوی بشپړ متن په خپلواکه توګه نه شي ترکیبولای.
- د خبرونو، روغتیا، قانون، پیسو او نورو حساسو موضوعاتو په اړه اصلي او باوري سرچینې په خپله هم وګورئ.
- د WhatsApp عادي ګډونوال د WhatsApp په اصلي سیستم کې په انفرادي ډول نه شي mute کېدای؛ له درېیم اخطار وروسته بوټ د تنظیم شوې مودې په اوږدو کې د هماغه غړي راتلونکي پیغامونه حذف کوي. بوټ باید د ګروپ مدیر وي؛ د بندیز حالت په موقتي حافظه کې دی او د سرور له بیاچالانېدو سره پاکېدای شي.
